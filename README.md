# Riverview College Alumni Homepage

A small, single-page React website made with plain HTML, CSS, and JavaScript.
There are no component libraries or CSS frameworks.

## Main files

- `index.html` sets the page title, description, favicon, and React entry point.
- `src/main.jsx` starts React and displays the page.
- `src/App.jsx` contains the navbar, hero, stats, about, events, and footer.
- `src/styles.css` contains all colours, layout, responsive rules, and effects.
- `public/` contains the hero photo and favicon.

## Run it locally

1. Install the project once with `npm install`.
2. Start it with `npm run dev`.
3. Open the local address shown in the terminal.

## Easy changes

- Change the college name and page text directly in `src/App.jsx`.
- Edit the `stats` and `events` arrays near the top of `src/App.jsx`.
- Change the main colours in the `:root` section of `src/styles.css`.
- Replace `public/alumni-gathering.jpg` with another image using the same name.

The college name, numbers, and event details are sample content and can be
replaced with real information.
